# luma-dental

Marketing site for a dental practice. App Router (`src/app`), TypeScript, Tailwind v4. Stack: Next.js 16.4 + React 19.3, GSAP (`gsap`, `@gsap/react`) for animation, `lucide-react` for icons.

## Commands

- `npm run dev` — dev server (Turbopack) at http://localhost:3000
- `npm run build` / `npm run start`
- `npm run lint` — ESLint flat config (`eslint.config.mjs`, `eslint-config-next`)
- No test framework or `test` script. Typecheck with `npx tsc --noEmit`.

## Stack quirks

- Next.js 16.4 differs from most training data. Read `node_modules/next/dist/docs/` before writing framework code.
- Tailwind v4 is wired through Turbopack, **not** PostCSS: `next.config.ts` has `turbopack.rules["*.css"] -> "@tailwindcss/turbopack"`. There is **no** `postcss.config.*` or `tailwind.config.*` — do not add them. Theme tokens live in `src/app/globals.css` under `@theme inline`.
- `cacheComponents: true` and `partialPrefetching: true` are enabled, changing the caching model: route segment configs `dynamic`, `revalidate`, `fetchCache`, and `dynamicParams` are removed — use `use cache` / `cacheLife` / `cacheTag`. Uncached data accessed outside `<Suspense>` fails the build with labeled fix options.
- Route-aware types `PageProps<'/route'>`, `LayoutProps<'/route'>`, `RouteContext<'/route'>` are globally available (no import); generated by `next dev` / `next build` / `next typegen`.
- Import alias: `@/*` -> `src/*`.
